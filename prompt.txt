You are asked to generate a reusable Python 3.10 script that finds branching-point intersections (degree ≥ 3) in *any* Linestring-only GeoJSON, and writes them to a new GeoJSON.

## Functional spec
1. **CLI arguments**

--in <input_geojson_path> (required)
--out <output_geojson_path> (default: intersections.geojson)
--snap <tolerance_meters> (float, default: 1.0)

2. **Processing steps**
1. Read input with GeoPandas.
2. Ensure CRS is EPSG:4326; re-project if not.
3. Merge all LineStrings (`shapely.ops.unary_union`).
4. Snap vertices within *snap* m (`shapely.ops.snap`).
5. Split lines into atomic segments (`shapely.ops.split`).
6. Count vertex degree; keep those with degree ≥ 3.
3. **Output**
* Write result GeoJSON to `--out`.
* Print summary: number of input features, number of intersections written.
